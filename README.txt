はたらくナビすぐワーク 採用LP
================================

■内容
- index.html：LP本体
- assets/css/style.css：デザイン
- assets/js/main.js：スクロール演出・フォーム入力チェック
- assets/img/logo.svg：ロゴ
- assets/img/hero-visual.svg：ファーストビュー画像
- send-mail.php：フォーム送信処理
- thanks.html：送信完了ページ

■公開前に必ず行うこと
1. send-mail.php を開く
2. 次の行を、実際に受信するメールアドレスへ変更
   $to = 'YOUR-EMAIL@example.com';
3. PHPが利用できるサーバー（XServer等）の公開フォルダへ、フォルダ内の全ファイルをアップロード
4. フォーム送信テストを行う

実際の制度に合わせ、対象者・支給額・支給時期・返還条件等を明確にしてから公開してください。
