公開方法:
1. ZIPを解凍
2. siteフォルダ内の index.html / assets / send-mail.php / thanks.html 等をGitHubまたはサーバーへアップロード
3. LINE URL（@yourlineid）を実際の公式LINE URLへ変更
4. GitHub PagesではPHPフォーム送信は動作しません。フォーム本番利用はXServer等へ設置してください。
