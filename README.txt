はたらくナビすぐワーク 求人LP
================================

【内容】
・参考サイトの雰囲気を取り入れた、青・黄・緑を基調とするオリジナルデザイン
・PC／スマートフォン対応
・生活支援金5万円をファーストビューで強調
・日本人の人物写真を使用
・ページを約60%スクロールするとLINE相談ポップアップを表示
・応募フォーム、送信完了ページ、PHP送信処理を同梱

【GitHub Pagesで確認する場合】
リポジトリ直下へ、index.html、assetsフォルダ、thanks.html、.nojekyllなどをアップロードしてください。
GitHub PagesではPHPが動作しないため、フォーム送信はできません。デザイン確認用として使用してください。

【XServerで本番公開する場合】
1. send-mail.php 内の YOUR-EMAIL@example.com を受信先メールアドレスへ変更
2. 全ファイルをXServerの公開フォルダへアップロード
3. フォーム送信テストを実施

【LINEリンク】
index.html 内の下記URLを、実際のLINE公式アカウントURLへ一括置換してください。
https://line.me/R/ti/p/@yourlineid

月収例、生活支援金、日払い、寮、交通費等は求人ごとに条件が異なるため、実際の募集条件に合わせて文言を調整してください。
